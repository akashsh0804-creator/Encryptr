Encryptr

Encryptr is a Python-based encryption tool designed to help users secure their documents using widely adopted cryptographic standards such as AES (Advanced Encryption Standard) and DES (Data Encryption Standard). This project was created as a way to explore and understand modern encryption techniques while providing a simple interface for real-world usage.

🔐 Overview

Encryptr offers multiple methods to encrypt and decrypt files with strong cryptographic algorithms. Whether you're learning encryption concepts or need a practical solution to protect sensitive documents, Encryptr provides a flexible and easy-to-use toolkit.

✨ Features

Multiple Encryption Algorithms

AES (various modes)

DES

Configurable Keys & Modes

User-specified keys, initialization vectors, and output handling

Beginner-Friendly

Simple command-line interface and clear structure

Python Implementation

Built using Python and common cryptographic libraries

To gain hands-on experience with cryptography.

To understand how encryption standards work at a deeper technical level.

To build a practical tool that demonstrates safe and correct usage of encryption algorithms.

To provide a foundation for future enhancements like:
